# NumPy Sales Data Analyzer

## Description
A beginner-friendly Python project that analyzes product sales data using NumPy.

## Features
- Calculate total units sold per product
- Calculate revenue per product
- Identify the best-selling product
- Analyze monthly sales
- Filter high-performing products
- Rank products by sales

## Technologies
- Python
- NumPy

## What I Learned
- NumPy arrays and array operations
- Aggregations using `np.sum()` and `np.mean()`
- Boolean indexing
- Sorting with `np.argsort()`
- Finding minimum and maximum values

## How to Run

Install NumPy:

```bash
pip install numpy
```

Run the program:

```bash
python sales_analyzer.py
```
